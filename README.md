# Arduino-Temperature-Monitor
Arduino temperature monitoring system with LCD display, LEDs, buzzer, TMP36 sensor, and potentiometer.


# Arduino Temperature Monitoring System

## Components

- Arduino Uno
- 16x2 I2C LCD
- TMP36 Temperature Sensor
- Potentiometer
- Red LED
- Yellow LED
- Green LED
- Buzzer
- 220 Ohm Resistors
- Breadboard
- Jumper Wires

## Features

- Displays temperature on the LCD
- Displays temperature status
- Green LED indicates normal temperature
- Yellow LED indicates warm temperature
- Red LED indicates high temperature
- Buzzer activates when the temperature is too high
- Potentiometer provides an adjustable input

## Arduino Pins

| Component | Arduino Pin |
|---|---|
| TMP36 | A1 |
| Potentiometer | A0 |
| Green LED | D7 |
| Yellow LED | D6 |
| Red LED | D8 |
| Buzzer | D5 |
| LCD SDA | A4 |
| LCD SCL | A5 |
